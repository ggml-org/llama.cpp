# llama-chat

The short name for [`@ggml-org/llama-chat`](https://www.npmjs.com/package/@ggml-org/llama-chat): `npx llama-chat` runs Llama Chat, the chat app for llama.cpp, on localhost and connects it to a llama-server.

```bash
npx llama-chat --server http://127.0.0.1:9931
```

This package only forwards to `@ggml-org/llama-chat`, at the same version. See its [README](https://github.com/ggml-org/llama.cpp/tree/master/ui/apps/chat#readme) for the options.
