# llama-chat

The short name for [`@ggml-org/llama-chat`](https://www.npmjs.com/package/@ggml-org/llama-chat): `npx llama-chat` runs Llama Chat, the chat app for llama.cpp, on localhost; the browser talks to your llama-server directly.

```bash
npx llama-chat
```

This package only forwards to `@ggml-org/llama-chat`, at the same version. See its [README](https://github.com/ggml-org/llama.cpp/tree/master/ui/apps/chat#readme) for the options.
